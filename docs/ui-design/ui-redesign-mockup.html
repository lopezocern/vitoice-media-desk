设计要点 微调落地的核心改动

  • 图标化侧边导航（SVG 注入 QIcon），加「工作台 / 系统」分组，设置页带 GPU 徽标
  • 侧栏与内容区加清晰层次：内容底 `#f4f6fb` 保持，卡片白底 + 阴影，主次分明
  • 主色微调至 #4f5bd5（同系更沉稳），新增 brand-soft/soft-2 两档浅色，用于 active/悬停
  • 概览模块卡 3 列网格 + 每模块图标，信息密度与点击舒适度提升
  • 控件精修：圆角 8→10px、悬停描边变主色、按压微下沉、进度条渐变

遵循记忆偏好 你之前强调的交互

  • 侧边栏默认常驻、可一键折叠（保留「≡」），不默认隐藏
  • 垂直 / 横版素材自适应显示：任务行按分辨率给出图标与元信息，不做固定宽度裁剪
  • 偏好集成美观界面、避免反直觉交互——本次只做视觉层，不改现有交互逻辑
  • 媒体感知：环境状态条显式标注分辨率 / 编码器 / CRF，一屏可读
