# MediaDesk · 真机验证清单

> 目的：在装有**完整版 FFmpeg** 的机器上，逐项跑通桌面台各模块的**端到端真实处理**。
> 背景：本机 FFmpeg 为精简裁剪版，只能离线断言命令，无法生成/验证真实处理；以下均为「真实跑一遍」的验收项。

---

## 0 · 环境准备（一次性）

- [ ] **ffmpeg / ffprobe 可从命令行调用（非精简版，含 libx264/libx265/libvpx/HEVC-NVENC 等）**
  - 验收：`ffmpeg -version` 正常；`ffmpeg -encoders` 能看到所需编码器
- [ ] **桌面台「全局设置」里 FFmpeg/FFprobe 路径已指向完整版（或用自动探测）**
  - 验收：状态标签不再提示精简版；配置能保存
- [ ] **准备 ≥1 个真实视频素材**（建议不同分辨率/编码各一个）
  - 验收：素材可播放、时长明确

---

## 1 · 视频压缩（阶段一）

- [ ] **单文件默认参数压缩**
  - 操作：导入 1 个视频，点「开始压缩」
  - 验收：进度条平滑到 100%，状态显示「完成」
- [ ] **输出文件正确性**
  - 验收：文件位于输出目录、可播放；ffprobe 抽查分辨率/码率符合所选（CRF、scale）
- [ ] **压缩率展示**
  - 验收：完成行显示「原大小 → 新大小」，体积变化符合 CRF 趋势（CRF 越大越省）
- [ ] **多文件并发**
  - 操作：一次拖入多个不同视频
  - 验收：并行队列正常、互不串文件，总时长合理
- [ ] **GPU 硬编**（有 NVIDIA 硬编的机器）
  - 验收：标签/日志显示 `hevc_nvenc`，速度明显更快，输出正常

## 2 · 视频切割（阶段二）

- [ ] **多时间段精确重编码**
  - 操作：1 个视频设 2 段时间，精确重编码
  - 验收：输出 `源名_1.<ext>`、`源名_2.<ext>`，进度 100%
- [ ] **时长与画面核对**
  - 验收：两段时长≈所填 开始~结束 区间，起止画面正确（帧精确）
- [ ] **快速流复制**
  - 操作：切快速流复制重切一次
  - 验收：秒级完成；首帧从最近关键帧对齐（起止允许小幅偏差），可播放
- [ ] **汇总统计**
  - 验收：「共 n 个 | 完成 | 失败 | 取消」数字对得上

## 3 · 视频拼接（阶段二）

- [ ] **同参数流复制拼接**
  - 操作：2 个同参数视频按序加入，快速流复制
  - 验收：输出 `<首前缀名>_concat.<ext>`；**无缝**（-c copy）
- [ ] **总时长核对**
  - 验收：ffprobe 总时长≈两段之和；可整段播放
- [ ] **不同编码统一重编码**
  - 操作：2 个不同编码/尺寸视频，精确重编码
  - 验收：统一编码成功，无黑屏/音画不同步；时长≈两段之和
- [ ] **临时列表自动清理**
  - 验收：输出目录无残留 `.*_concat.txt`

## 4 · 格式转换（阶段二）

- [ ] **mp4 → webm（平衡，保原尺寸）**
  - 验收：输出 `源名.webm`，ffprobe `codec_name=vp8`，可播放
- [ ] **mp4 → mkv + 固定分辨率 1280x720**
  - 验收：ffprobe width/height = 1280/720
- [ ] **去掉音频**
  - 验收：ffprobe 无 audio stream
- [ ] **仅提取音频**
  - 操作：勾选「仅提取音频」转换一次
  - 验收：输出 `源名.m4a`（aac），无视频流，可播放
- [ ] **GPU 硬编**（有 NVIDIA 硬编的机器，mp4→mp4）
  - 验收：`hevc_nvenc` 生效，输出可播放，速度更快

---

## 5 · 验收汇总

- [ ] **四大模块至少有一次真实成功**（压缩/切割/拼接/转换均满足）
- [ ] **全程无崩溃、无卡死；停止/取消可用**（处理中按「停止」能中断）
- [ ] **硬编/软编情况已记录**（结论标注识别到的编码器与回退情况）

> 通过建议：各模块勾齐「真实处理成功 + 进度到 100%/完成」即可判定通过；
> GPU 回退若有 NVIDIA 硬编机器另测；所有输出用 ffprobe 抽查确认参数符合所选。
