# 文件整理模块重构 · 需求要点清单（轻量核心版）

> 依据：16 张批量重命名器截图 + 需求对齐。浅色主题。

## 已确认决策（2026-09-11 用户拍板）
1. **界面承载形态**：页⾯式 —— 集成在左侧导航「文件整理」页内（扫描目录 → 加载 → 配置 → 实时预览 → 应用），**不做独立弹窗**。
2. **缩略图**：右侧预览表**不显示缩略图**，纯文本「原名称 → 转换后名称」。
3. **媒体库变量**（标签名 / 来源网站 / 导入时间）**暂不支持**，但**保留按钮入口**——点击提示「暂无数据源」，不纳入本轮。

## 目标
把「文件整理」从「拼音前缀 + 垃圾清理」升级为**规则驱动的批量重命名器**，落地前干跑预览、确认后执行。

## 本轮范围（核心版）

### 界面（复刻截图交互，浅色主题）
- **左：规则配置面板**——操作类型下拉 + 随操作联动的参数区 + 通用选项。
- **右：文件预览表**——每行 `原名称 → 转换后名称`，规则一变立即实时刷新（防抖重算、只刷新变化行）。
- 流程：选目录 → 扫描加载 → 改规则实时看预览 → 「应用更改」（二次确认）→ 落地。
- 数据源：沿用「选择一个目标目录」，命令行加载其子项。

### 5 类规则
1. **查找替换**：查找 / 替换 + 使用正则 · 忽略大小写 · 全部替换。
2. **组合命名模板**：模板文本框 + 变量按钮（${原名称} ${日期时间} ${序列号} ${随机串} ${UUID}）；内置**拼音前缀预设**。
3. **删除字符**：起始位置 + 删除字符数 + 计数起点（开头/末尾）。
4. **转换**：小写 / 大写 / 标题式大写 / 首字母大写 / 移除特殊符号(äé→ae) / URL 解码。
5. **设置扩展名**：新扩展名 + 「只更改现有扩展名」。

### 变量语法（${...}）
`${original}` `${folder}` `${create_time:fmt}` `${modify_time:fmt}`
`${seq:start=1;increment=1;padding=3}` `${random:N}` `${uuid}`
时间格式：`yyyy MM dd HH mm ss`。

### 通用选项
- **保留扩展名**（默认勾选）：规则只作用主名，落地再拼回原扩展名。
- 垃圾**清理**保留为独立动作（沿用现有垃圾文件规则 + 二次确认）。

## 安全
- 全程干跑预览；应用前二次确认；清理删除单独确认；`PermissionError` 不中断整体。

## 明确不做（后置）
- 图片缩略图预览、过滤栏、新名冲突标红。
- 标签名 / 来源网站变量（无数据源，剔除）。
- `import_time`（无“媒体库”概念，只做 create/modify）。
- 规则预设持久化、跨多目录导入。

## 验收示例
| 场景 | 预期 |
|---|---|
| 10 张 `photo_*.jpg` 组合模板 `${create_time:yyyy-MM-dd}_${seq:start=1;increment=1;padding=3}` + 保留扩展名 | `2026-07-28_001 … 010.jpg` |
| 正则 `^Z ` 替换空 | `Z 张韶涵_P_019.jpg → 张韶涵_P_019.jpg` |
| 删除：起始 0 删 5 开头 | 去掉前 5 字符 |
| 转小写（保留扩展名） | `Z 张韶涵_P_019.jpg → z 张韶涵_p_019.jpg` |
| 设扩展名 `.jpeg` + 只改现有 | 带扩展名→.jpeg，无扩展名不动 |
| 拼音预设 | 中文开头加拼音首字母，英文/序号开头跳过 |
