# MediaDesk 使用说明

MediaDesk 是一个 PySide6 桌面客户端，把多个 FFmpeg 能力收拢到统一界面。本文按模块说明操作流程。

## 界面布局

- **左侧侧边栏**：模块导航，可点击标题栏折叠按钮（☰）收藏侧边栏，收起后内容区自动铺满。
- **底部状态栏**：显示运行中 / 完成 / 失败任务数与硬件加速状态，「停止全部」可批量取消。
- **标题栏**：可拖拽移动窗口、边缘/四角拖拽调整大小、双击标题栏最大化/还原。
- 所有关键控件悬停可显示说明气泡（`?`），输入框 / 下拉 / 复选均有明确的 hover 反馈。

打开程序后建议先看一眼顶部「总览」页的环境状态条：确认 FFmpeg 与 GPU 编码器是否就绪；红色圆点表示某能力未就绪。

---

## 1. 视频压缩

把单个/多个视频压缩变小。

1. 把视频拖入上方虚线框，或点击虚线框选择文件（支持常见视频格式）。
2. 在「输出设置」展开画质 / 分辨率 / 码率等的定制：
   - 启用 GPU 后编码器胶囊会显示实际硬编编码器（如 `hevc_nvenc`），未启用时显示软件编码（如 `libx264`）。
   - 「展开高级参数」可查看更多选项。
3. 点击「开始压缩」，任务列表实时显示进度；可暂停/取消单个任务。

## 2. 视频切割

把视频按时间段切出若干段。

1. 拖入视频，点击任务行的「时间段」按钮打开时间段弹窗。
2. 设置各段时间（时 / 分 / 秒）：
   - 新增段起点会自动接上一段结尾，也可手动改。
   - 段结束须晚于开始；若无效，弹窗内会标红提示「时长无效」。
3. 选择「快速切割」或「精确重编码」后开始。切割页支持多个时间段一次切完。

## 3. 视频拼接

把多个视频按顺序合并成一个。

1. 依次拖入/添加视频（可用 ▲▼ 上移下移排序，✕ 移除）。
2. 选择「快速拼接」或「统一重编码」。
3. 开始后实时显示进度。

## 4. 格式转换

mp4 / webm / mkv 等容器互转，或仅提取音频。

1. 拖入文件，选择输出格式（mp4 / webm / mkv）。
2. 可设置分辨率、画质、是否启用 GPU 编码。
3. 勾选「仅提取音频」可把视频转成 `m4a` 音频，不处理画面。
4. 开始转换。

## 5. 文件整理

批量给文件改中文名加拼音前缀、并清理垃圾文件。

- 拖入需要整理的文件，配置命名规则（可插入时间戳、序号等变量）。
- **先「干跑预览」**查看转换前后的名称对照；确认无误后再执行正式整理。
- 内置「清理垃圾文件」功能，可一键移除指定类型的残留文件。

> 整理、清理属**不可逆操作**，请务必先用干跑预览核对。

## 6. 全局设置

集中管理运行环境：FFmpeg 路径、GPU / 编码器开关、默认输出目录、并发任务上限等。这里的 GPU 设置会同步到压缩 / 转换各页。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 环境圆点显示未就绪 / 编码器灰色 | 检查「全局设置」中 FFmpeg 路径：手动路径 > 随包 `ffmpeg/bin` > 系统 PATH |
| 想要更快但 GPU 未生效 | 确认 FFmpeg 版本支持 NVENC，并在「全局设置」开启硬件加速 |
| 找不到某功能没展示全 | 拖拽窗口边缘扩大窗口，子界面滚动可查看全部功能 |
| 压缩/转换无进度或任务卡住 | 点底部「停止全部」取消后重新添加任务 |
